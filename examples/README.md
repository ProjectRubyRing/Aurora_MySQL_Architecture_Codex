# 設定例の位置付け

これらは設計レビュー用の例で、AWSやDBへの設定変更は実行していません。

- `ecs-container-fragment.json` は完全なタスク定義ではありません。東京・大阪の同じSSMパスへ、それぞれの地域のRDS Proxy RWホストを事前登録します。ECSの実行ロール、CPU/メモリ、ネットワーク、ログ、ヘルスチェック、Secretsの供給は実環境で定義します。イメージのURIは地域別、digestは同一です。
- `online-datasource.cli` は事前にMySQLドライバmoduleとElytron credential storeを準備する例です。XMLで書くときはURL中の`&`を`&amp;`にします。全サーバー共通のJTA期限変更は専用オンラインサーバーの例で、他のアプリが同居する場合はトランザクション単位の期限を設計してください。CLIの全属性の可否は導入するEAP 8.1の管理モデルで確認します。
- `BatchConnectionExample.java` はJDK 17で構文確認する最小接続例です。DB接続の実行にはConnector/J、地域設定、DBユーザー、厳格な権限の秘密ファイルが別途必要です。ジョブ全体60分・チャンク180秒の期限、最大8 worker、冪等性・チェックポイントはジョブ本体の設計事項で、この例が実装済みと扱わないでください。`readClock()`は時計の読み取り例です。
- JDBC URLに使うホストはリージョンのProxy固有FQDNです。`DriverManager`を直接使うことはAuroraへ直結することとは違います。例の検証は既定RWエンドポイントの形式に限定しています。追加Proxyエンドポイントを採用する場合は、登録済みFQDNの許可リストへ置き換えてください。
- `runtime-verification.sql` は参照SQLのみです。実機での値・認証ユーザー情報は機密資料として保管してください。Proxy経由では物理接続が再利用されるため、インスタンス単位の厳密な採取は承認済み管理経路から行います。
- `partition-example.sql` はDDLの説明例です。実行はしていません。複合主キーにすると`event_id`単独の一意性は保証されず、分割InnoDB表には外部キー制限があります。分割を採用する前に論理設計を確認してください。

これらの例に、実環境のホスト名、アカウントID、パスワード、秘密ARNは含めていません。
